# UI Behavior Test Matrix: Team Tab Active Tasks

This matrix is derived from the canonical UX contract in `complete-ux-ui-design.md` and the journey in `experience-story.md`. It intentionally rejects the earlier duplicate-right-reference layout and treats Messages content/reference UI as a frozen baseline while requiring the Messages header left chevron.

| test_id | area | start_state | trigger | expected_state | expected_feedback | must_not_happen |
| --- | --- | --- | --- | --- | --- | --- |
| `T-001` | Team tab default | Team tab opened | none | Messages open; Active Tasks collapsed | Messages and Active Tasks headers use Activity-style left chevrons; Active Tasks count says `0 tasks`, `1 task`, or `N tasks`; Messages list/detail/reference UI remains baseline | Active Tasks auto-opens because tasks exist; header says `2 Active`; Messages content/reference UI gets restyled |
| `T-002` | Active Tasks toggle | Active Tasks collapsed | click Active Tasks leading chevron/header | Active Tasks expanded | Left task navigator, draggable vertical divider, and right selected-content pane appear; first available task selected | Active Tasks row expansion inside list instead of split layout; fixed-width task navigator with no divider |
| `T-003` | Empty state | Active Tasks expanded with no active tasks | none | Empty state | Shows calm `No active delegated tasks` style message | Shows blank broken pane or technical IDs |
| `T-004` | Individual-target task selection | Active Tasks expanded | click task row | Task selected | Left task row highlighted without `Task Agent` badge; reference files, if present, appear nested under selected task in the left navigator; right pane shows target/status/`Focus`, task body, collapsed Technical details | Visible `Task Agent` badge; right task detail duplicates reference rows by default; visible `Task brief` heading when content is obvious; Approve/Deny buttons |
| `T-005` | Group/team-target task selection | Active Tasks expanded | click group/team task row | Group/team task selected | Left task row highlighted without `Task Team` badge; references, if present, appear nested under selected task; right pane shows target/status/`Focus`, task body, member Focus rows, collapsed Technical details | Visible `Task Team` badge; separate second row like `Review implementation [Focus team]`; right duplicate reference section; Approve/Deny buttons |
| `T-006` | Task reference preview | TaskAgent or TaskTeam selected with nested reference rows | click nested reference row in left navigator | Reference selected | Reference row highlighted; whole right pane switches to loading then read-only file preview/error, using Messages-like file viewer behavior | Reference hidden inside Technical details; preview opens in tiny inline block; task body and file preview compete side by side |
| `T-007` | Return from reference | Reference preview visible | click the selected task row | Task detail restored | Right pane returns to selected task body; selected task remains highlighted | Task-specific `Back to task` button appears; task selection lost unexpectedly |
| `T-008` | Focus individual target | Individual-target detail visible | click `Focus` | Target focused in workspace | Team tab selection persists; no task row collapse | Visible button says `Focus agent`; Focus button appears as a second title row |
| `T-009` | Focus group/team target | Group/team-target detail visible | click `Focus` | Target focused in workspace | Team tab selection persists | Visible button says `Focus team`; Focus buried in Technical details |
| `T-010` | Focus member | TaskTeam detail visible | click member Focus | Member focused in workspace | Member row remains clear and compact | Member focus unavailable when member identity exists |
| `T-011` | Waiting status | Task is blocked/waiting | task selected | Calm waiting status visible | Header/status may say `Waiting approval`, `Waiting input`, or `Waiting action` | Dominant `Approval required` badge; Approve/Deny controls in Active Tasks |
| `T-012` | Technical details | Task detail visible | expand Technical details | IDs/provenance visible | Shows task/team/member IDs, run IDs, raw args if needed | Reference files appear only here; technical details open by default |
| `T-013` | Messages header + content baseline | Messages section open | inspect header/list/detail and click existing message reference | Existing message reference preview opens | Messages header uses Activity-style left chevron; list rows, nested refs, selected states, detail pane, preview controls/layout/states remain baseline | New task viewer route breaks message references; shared extraction changes Messages content spacing/classes/controls |
| `T-014` | Backend/projection data | TASK_DELEGATION_EVENT contains refs/args | event projected | ActiveTaskEntry includes task refs/args | UI can render left nested task refs without scraping messages | Row component infers refs from communication messages or raw DOM/data |
| `T-015` | Electron visual validation | Implementation complete | run Electron-backed UI and inspect | UI passes human visual review | Engineer records scenario/commands/iterations; if cramped or confusing, code is updated and rechecked | Handoff without live UI inspection |
