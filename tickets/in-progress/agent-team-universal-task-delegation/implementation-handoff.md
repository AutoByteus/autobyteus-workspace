## Important Assumptions

- Current runtime reads and writes only the V1 TeamRun package and current V6 application identity; predecessor knowledge is migration-only.
- A task record is authoritative for delegated-work relationship, while execution-tree containment alone is authoritative for concrete ancestry.
- Accepted/interrupted task execution may remain materially live until open child work and the exact local runtime are idle. Settlement preparation is reversible and non-destructive until tree durability commits.
- Ordinary AgentRun termination closes admission but drains prior reserved/committed/released input in FIFO order. Only the root-fail-stop path may dispose a deliberately hidden finalization-indeterminate reservation.
