## What's New
- Settings > Token Statistics task rows now use a cleaner nine-column table that removes redundant standalone Type and Status columns.

## Improvements
- Sortable task-table headers now show compact persistent two-triangle sort indicators, including neutral glyphs for inactive sortable columns and an active direction cue for the current sort.
- Cost breakdowns now open from one always-visible icon-only disclosure in the Total Cost cell, instead of hidden hover-only cost-cell actions.
- Non-complete pricing states remain visible through formatted Total Cost text and in the expanded breakdown, while normal complete estimates no longer repeat in every main row.

## Fixes
- Input Cost and Output Cost now render as plain values, avoiding duplicate controls that all opened the same row details.
- Expanded member rows stay attached to their parent after Total Cost sorting with the reduced table layout.
