## Reading
- main frame of the node's origin: the object exists; its showNodeList opens the app's Switch node list (positive control).
- sandboxed frame (opaque origin, the preview pattern): typeof AutoByteusShell = undefined; parent.AutoByteusShell -> SecurityError; nothing reached the app.
- sandboxed blob: frame (exactly HtmlPreviewer): never loads in the app; the WebView's existing navigation containment blocks blob: and shows "Navigation blocked" (pre-existing, AutoByteusWebView navigation policy unchanged by this ticket) -> follow-ups.md FU-005.
- same-origin NON-sandboxed subframe (not produced by /mobile): its own object's showNodeList was ignored (main-frame rule), but it can call the PARENT's object, which posts as the main frame:
  startScan opened the scanner. Same-origin script already has the page's credential in localStorage, so this is not a new privilege; no product path renders such a frame on /mobile.
