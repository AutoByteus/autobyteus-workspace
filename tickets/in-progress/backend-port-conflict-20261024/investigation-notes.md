- E-009: electron/application/electronApplication.ts:346-356 starts an 8s timer at before-quit, calls void this.stop() at will-quit without preventDefault; stop() clears the timer before awaiting backend stop. Electron's documented will-quit does not wait for an asynchronous listener: https://www.electronjs.org/docs/latest/api/app (read 2026-10-24). This establishes a source/dependency-contract gap; actual changed-build quit must still be validated. Windows OS logout/shutdown does not emit these events; outside the promised orderly shutdown boundary.

A non-throwing early native-command drain plus final aggregated failure can run without suppressing the rest of cleanup. - E-011: read-only lsof feasibility on a task-owned ephemeral IPv6 listener: /usr/sbin/lsof -nP -iTCP:65533 -sTCP:LISTEN -Fpc, execFile timeout1000/maxBuffer32768, returned p60154/cnode/f12. Changed-build conflict validation must start clean then arrange a test-owned conflict for restart, or use a separate isolated source harness; do not weaken isolation guards or patch installed app.

Installed electron-updater6.8.9 BaseUpdater starts install before app.quit; MacUpdater delegates to native quitAndInstall.
