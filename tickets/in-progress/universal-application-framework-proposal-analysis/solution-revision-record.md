  - Defined mixed-runtime editing: blank team-wide fields mean per-member inheritance; a common inherited runtime may drive bulk model choice; mixed inherited runtimes disable bulk model selection until an explicit common runtime is saved. No AutoByteus/previous-result fallback is allowed.
  - Added one `ApplicationPortableLaunchConfigPolicy` with closed runtime/root/pricing schemas and recursive object/array traversal. It preserves exact `max_tokens`, `token_limit`, `safety_margin_tokens`, and typed pricing fields, while rejecting password/passphrase, secrets/credentials, API/private keys, authorization/bearer, access/refresh/ID-token values, endpoints/base URLs/API bases/hosts, workspaces, and machine paths at any depth. Diagnostics carry exact paths/reasons but never values. No app-specific/compatibility exception is permitted.
  - Preserved current rows/schema as `Directly Usable — No Migration`; manifest/selected baselines and preview are computed only. Preserved complete Codex/Luna defaults, three readiness statuses, invalid-row/no-fallback behavior, standalone pre-listen gate, graph-local prompt authority, package immutability, no-auth scope, and all prior composition decisions.
  - Added SV-C33–SV-C35 for unsaved alternate preview/race, saved alternate field clearing/mixed runtime, and recursive portable positive/negative behavior. Recorded that API/E2E must replace the obsolete no-context auto-repair test after source review passes.
