## Paste (phone → node desktop)
desktop clipboard before: BEFORE-426 (xclip, set in the container)
Clipboard → tap the Paste box (real tap, the system keyboard opens) → typed "PHONE-TO-DESKTOP-426" with the system keyboard
  (adb input text; the emulator has no shell command to put text on the phone clipboard for a paste) → value "PHONE-TO-DESKTOP-426" (API-09-3-paste-typed.png)
tap "Send to desktop" → docker exec -u vncuser api426-node sh -c 'DISPLAY=:99 xclip -o -selection clipboard' → "PHONE-TO-DESKTOP-426"
  sheet closed after the send; status still "Connected · Control" (API-09-4-after-send.png)

## Copy (node desktop → phone)
in the container: printf DESKTOP-TO-PHONE-426 | DISPLAY=:99 xclip -selection clipboard
Clipboard sheet: remote text "DESKTOP-TO-PHONE-426", Copy enabled (API-09-5-copy-sheet.png)
tap "Copy" (real tap) → button "Copied", no fallback line (API-09-6-after-copy.png)  — programmatic copy works on http:// in this WebView (U-01)
phone clipboard check: tap the Paste box, clear it, KEYCODE_PASTE (the system paste) → value "DESKTOP-TO-PHONE-426" (API-09-7-phone-clipboard-pasted.png)
