## Changes

- A stopped AutoByteus run whose model is no longer available, for example one you removed from LM Studio, can now continue on another model. Open the run's Settings, choose any model the list offers, and press Save. The message says "Model saved. Your next message starts a fresh session on the new model, which continues from the work journal."
- Your next message starts a fresh session on the new model. The chat shows "Model changed from … to …", and the new session continues from the run's work journal. Earlier messages stay in the chat.
- This also applies to a model with a smaller or unknown context window than the one the run last ran on. A model with a verified equal or bigger window keeps the same session, as before. A Team or Organization member, and a delegated copy, behave the same way.
- The help text under the model menu now says so, in English and Simplified Chinese.
