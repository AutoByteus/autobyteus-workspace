## Links in Markdown files open the linked file, and workspace choices list only places to run

- In the Files panel (the Skills page, your workspaces and the read-only memory folder view), clicking a relative link in a Markdown file now opens the linked file in a preview tab of the same folder. A link to a file that does not exist opens its tab, which says the file was not found, and a link that leads out of the folder does nothing. Web links and links to a heading in the same file work as before. In a read-only folder nothing becomes editable.
- The workspace menu when you start a chat or change Run Settings, and the phone's launch picker, now offer only your folders and the temporary workspace. A skill's folder, which is a place to read, is no longer offered as a place to run. Leaving the Skills page while a skill is still loading no longer leaves its folder registered.
- When the availability check of the Grok Build or Antigravity runtime is slow because the computer is busy, the app now reports that it timed out, instead of "Grok CLI version or agent mode is unsupported; update to 1.0.41 or later". A check whose command had already answered is no longer reported as timed out. The server log names the command and the time limit when a check really times out.
