# Ubuntu desktop startup
Open the official Linux AppImage normally. On Ubuntu desktops that restrict the Chromium sandbox, the new launcher offers a protected installation. The first install needs an internet connection and one Ubuntu administrator authorization. Afterward, open AutoByteus from the menu or reopen a download that includes the new launcher. On desktops that already support the sandbox, the AppImage remains portable.

Your settings and work stay in place. If automatic updates are enabled, a verified update waits for your next ordinary quit and leaves the app closed. Choose **Install and Restart** to reopen immediately. If setup fails, follow the recovery message rather than disabling the sandbox.
