# Managed Ubuntu automatic updates
With **Update automatically** on, AutoByteus now starts installing a verified update immediately instead of waiting for agent work to finish or for five minutes without input. A running turn can be interrupted. After restart, the recorded run receives an update notice and you can continue the conversation. Turn automatic updates off if you prefer to choose when to install.

Quit still leaves the app closed. Before verification finishes, Quit leaves the old version installed; after installation starts, it can finish without reopening.
