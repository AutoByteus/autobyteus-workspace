Concept visualization · not a proposed storage schema

One understandable view, three durable authorities.

The UI projects the rooted execution tree, delegated tasks, and communication records into one view because people understand work hierarchically. The three stored authorities stay separate. A message is shown only as activity—it never becomes a structural edge.

Underlying truth

Separate authorities

The display joins them; the domain does not collapse them.

TeamRun execution tree

Mounted logical placements, launch facts, concrete TeamRun and AgentRun identities, containment, and task-execution lifecycle.

Task ledger

Delegator, recipient address, fresh assignee execution, status, result, and review.

Communication history

Exact sending and receiving AgentRun IDs, content, type, references, and time. No structural link is stored.
