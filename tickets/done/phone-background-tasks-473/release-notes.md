## Improvements
- The phone's **Activity** for an agent now shows its background tasks above the tool calls: each with what it runs, whether it is running, completed, failed or stopped, how it ended (for example "exit code 1") and when it started, updating live.
- Background tasks that started before you opened a run, or before a reload, now show at once on the phone and in the desktop's Background Tasks panel, for Claude, AutoByteus and Antigravity runs, as they already did for Codex.
