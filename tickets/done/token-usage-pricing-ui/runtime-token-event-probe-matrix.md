## Runtime Normalization Consequences

- The final agent-run token statistics shape should not be provider-only; it must also accept runtime-native events from Codex and Claude Agent SDK.
- Runtime-native fields should map into the same canonical event fields: reported/accounting input/output/total, cache read/create, reasoning output, billable output, model identity, raw usage/event JSON, quality flags, and cost fields.
- Reasoning/thinking tokens remain an output sub-breakdown when numeric counts are available. They must not be added a second time to output tokens/cost.
- If a runtime exposes thinking content but no numeric thinking token count (observed Claude Agent SDK), show accurate total output tokens/cost but no reasoning subline; mark the raw event/probe matrix so this is an availability limitation, not a missing cost.
