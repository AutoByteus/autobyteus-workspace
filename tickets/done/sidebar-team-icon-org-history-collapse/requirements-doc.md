## Problem and outcome
Workspace sidebar Team definition headers fall back to initials; Org headers always use a generic icon even when a definition has an avatar. Individual live Org run rows cannot collapse through their displayed chevron. Users should recognize Team containers and independently show/hide an Org run's descendants without changing current work.
