## What you need to do
- **Nothing extra for this beta's features.** Update the desktop app and your nodes as usual (the app and each node restart for the update). The phone's new screens (Settings, Text size, the easier-to-read conversation) come from the node you open from the phone, so update that node; the Android app needs no update for them. This beta's Android APK and TestFlight build are published as with every release.
- **The first update from 1.5.13-beta.8 into this beta:** agents that were in the middle of a turn are woken with a short reminder that the application restarted for the update to v1.5.13-beta.9, that their turn was interrupted, and that any background tasks they had started were stopped. Agents that were idle while a background task of theirs was still running are **not** told this time, because beta.8 did not keep track of them; their background tasks were stopped by the update all the same, so check any long jobs you had running. From the next update after this beta, those agents are told too.

## Good to know
- **Smaller downloads.** The desktop apps and the Docker server package no longer include an unused copy of Claude Code: desktop downloads are about 75 to 190 MB smaller depending on the platform, and the Docker server package about 233 MB smaller. Claude agents keep running with the Claude Code you installed, as before; where it is not installed, Claude agents show as not available, as before. This was checked with a build of all five desktop targets and a Claude run in the packaged macOS app; a Claude run on Windows, on Linux and inside a Docker node was not tried.
- In the phone's **Settings**, a model that has no usage left is not marked as such.
- In the conversation view, the restart reminder can show twice after a restart, and the agent's first reply before the restart may be hidden. The agent receives the reminder only once.
- In our check, a Grok agent was not woken when its background command ended. It can still wait for the command itself.
