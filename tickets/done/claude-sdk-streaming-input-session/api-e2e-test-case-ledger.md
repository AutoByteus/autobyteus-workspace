- OBS-1 (C13): the Claude CLI (2.1.283 and 2.1.280) blocks `sleep N; …` foreground chains ("Blocked: sleep 25 followed by … use run_in_background: true"). Live tests use a python sleep for long foreground work and assert the process is running before a Stop or kill.
- OBS-2 (C15): an inherited `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` in the server's own environment silently disables background tasks, because AutoByteus no longer overrides it (REQ-009). Seen here because the dev stack was launched from this agent's AutoByteus-spawned shell. Low risk (an operator environment issue), but it matches how the v1.4.78 policy reaches children of an older AutoByteus.
