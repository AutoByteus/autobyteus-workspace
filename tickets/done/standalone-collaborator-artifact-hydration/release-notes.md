# Release Notes — Collaborator Artifacts in standalone runs

## Fixed

- **Collaborators of a standalone agent now show their full Artifacts list after a page reload and on historical runs.** This covers Agents and Team members brought in with `@` or by the agent. Before this fix, a collaborator's Artifacts tab showed "No touched files yet" after a reload or when opening a past run. Now every file it produced is listed and previews, the same as for Team and Agent Org members.
