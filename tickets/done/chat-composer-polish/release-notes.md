# Chat composer polish

## Changes
- **Picking a thinking level now turns thinking on.** For models with a thinking on/off switch (such as Claude), the thinking menu is now one list: Off, then each level (for example Low, Medium, High, Xhigh, Max). Picking a level turns thinking on at that level, and Off turns it off. The button shows the level in use, or "Off".
- **Same rule in run settings.** In the launch form and ⚙ run settings, changing a thinking setting under Advanced while Thinking is off now turns Thinking on.
- **Search workspaces in a New chat.** The workspace menu has a search box. Type to filter by name or path, use the arrow keys to move, and press Enter to pick. "Open another folder…" is always available.
- **The New chat message box sits a little lower** on the page.
