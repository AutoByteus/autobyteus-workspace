## What's New

- A Project Task can now be part of a bigger Task. Choose its parent in the new "Part of" field when you create or edit a Task, or use "New part" on the parent's Task page. There is one level only: a part cannot have parts of its own.
- A parent's card on the board shows how many of its parts are done. Its Task page and the Projects tab list its parts with their status. A part's card and page show the Task it belongs to, and open it with one click.
- When a parent Task is set to Done or Cancelled, its open parts are set the same way and their task agents stop. The parent's page says so while it has open parts.
- Deleting a parent keeps its parts as separate Tasks, and the delete confirmation says how many there are.
- Agents can set, change and clear a Task's parent with the Project Task tools. Task lists and search results show each Task's parent and parts.

## Upgrade Notes

- Existing Tasks need no conversion. They simply have no parent.
