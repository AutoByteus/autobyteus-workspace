# Release Notes — Cleaner delegated rows in the Workspaces tree

## Changed

- **Delegated rows now look like the other tree rows.** In the Workspaces tree, Agents and Teams started by delegation no longer sit in a dashed indigo box. This applies under Agent, Team and Agent Org runs. At rest they have no border or tint, and they get the same light-gray hover, the same keyboard focus ring and the same selected highlight as normal member rows.
- **Delegated Teams are marked by a bolt.** A delegated Team now shows a plain slate bolt icon and a bold name. Delegated Agents keep their status dot and initials.
- Clicking, Enter/Space, expand/collapse, tooltips and tree lines work as before.
