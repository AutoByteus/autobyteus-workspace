AutoByteus NFS

AutoByteus NFS is an independent host storage service. AutoByteus uses ordinary filesystem paths and does not detect or manage the underlying storage.

2. Choose what this computer does

After installation: create on the storage host, then connect the other computers. These commands are interactive and may request administrator approval.

Create storage once
Copy

On the storage host, choose an existing or new source folder and trusted computers or private subnet. Existing files stay in place; review administrator changes before approving.

Connect each other computer
Copy

On each other host, paste the connection JSON printed by create. Review and approve the setup. Application and container configuration stays separate.

~/.local/bin/autobyteus-nfs connect
3. Installed commands

Run these only after installing the CLI. Commands use its explicit path, so no PATH setup is needed. Except for version, they may request administrator approval.

Interactive menu
Copy

Open setup or saved-state options without arguments.

~/.local/bin/autobyteus-nfs
Check status
Copy

Report actual host readiness. This can wait while checking storage or the network.

~/.local/bin/autobyteus-nfs status
Reconnect
Copy

Resume saved storage or pending setup with consent. This is not data recovery.

~/.local/bin/autobyteus-nfs reconnect
Detach safely
Copy

Stop users of the mount first, then review and approve detach. Source files and private data are preserved.

~/.local/bin/autobyteus-nfs detach
Show version
Copy

Print the installed version without configuring storage.

~/.local/bin/autobyteus-nfs version

Use the printed mount path as a normal folder.

Use only on a trusted private network

NFS is unencrypted—do not expose it to the internet.

If storage or the network goes offline, file operations and other work may stall. Restore connectivity before retrying.
