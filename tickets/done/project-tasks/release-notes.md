# Release Notes — Project Tasks (Projects preview)

## What's new

- **Tasks in Projects.** Each Project page now has a **Tasks** tab with a three-column board: **To Do**, **In Progress** and **Done**. Write a Task as a free-form description; the card shows the description itself.
  - Create, view, edit, and delete Tasks. New Tasks start in **To Do**.
  - Search all of a Project's Tasks from the board.
  - Each Project card on the Projects page now shows its open Tasks and workspaces, for example "3 open tasks · 2 workspaces".
  - Deleting a Project also deletes its Tasks. The confirmation tells you how many Tasks will be removed.
- **Roomier Project page.** A Project now opens on a full-width page with **← Projects** at the top-left to go back. The page has **Tasks** and **Workspaces** tabs, and the link to either tab can be bookmarked. When space is tight, for example with the side panel open, the three columns stack instead of getting squeezed.

## Compatibility

- No migration. Projects created with v1.4.86 open unchanged and simply start with no Tasks.
- Projects is still off by default. Turn it on in Settings → Server Settings → Basics → **Projects**. English and Simplified Chinese are supported.
