## Reference files of delegated agents and teams open from the Messages tab

- In the Messages tab, a reference file attached to a message now opens whichever run holds that message. Before, clicking a file in the tab of a delegated task team member, a delegated task agent, or a member of a task team inside an Org could show "Reference file unavailable", although the message and its file were listed. The root's own Messages tab also opens the files of messages between its agent and its delegated runs. Files in the phone's Messages screen open the same way.
- When a file cannot be opened, the viewer now says why. "This file's message could not be found in this conversation." means the node does not hold that message; "The file may have been deleted, moved, or become unreadable." means the file itself is gone or cannot be read.
- Context files (the files you attach to a run) open as before.

## What you need to do

- Update the app and every node you connect to together. An app and a node of different versions cannot open each other's message reference files: the link the app uses changed, and the old one is gone.
