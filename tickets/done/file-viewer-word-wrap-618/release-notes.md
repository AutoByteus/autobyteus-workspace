## Text and code files wrap in the file viewer

- Text and code files now open with word wrap on. A long line wraps at the editor's width instead of running past its edge, on the phone and on the desktop, so files such as a workspace config, a JSON file or a draft written as one long paragraph read without sideways scrolling. A wrapped line keeps the indentation of its line, and line numbers stay one per line. Editing, saving and highlighting work as before.
- The same applies wherever the app shows a text file in its editor: the Files tab, the phone's Files screen, and the viewers for message references and artifacts.
- To turn wrap off for the file you are reading, use the editor's right-click menu, "Toggle Word Wrap". The choice is not remembered for the next file.
- In the desktop Files tab, the editor beside the file tree is narrow at common window sizes, so wrapped text there shows only a few words per row; maximize the editor for the full width.
