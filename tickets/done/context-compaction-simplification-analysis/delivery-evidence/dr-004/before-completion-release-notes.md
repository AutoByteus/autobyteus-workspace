  original attachments/identity and FIFO order, without consumed-work replay.

  ordinary repair; preserve historical inspection/frozen converter boundaries.

  Agent-root collaborators and hosted-Team members with exact lifecycle guards.

  live pending presentation by scoped tagged primary identity; no semantic guessing,
  old-key migration/backfill, backend-restart queue or native cold journal.
- Preserve original web/core boundary; native-history integration test belongs
  outside web. Remove unsupported reporting flag; retain reporting guards.
- Synchronize canonical memory, history, runtime, settings and UI docs.
