## Main design decisions / review focus

- **Content contract:** `CompressionStrategy.compress(content: string): Promise<string>`. Caller plans/renders complete selected content, prior summary once. Operation factory binds cancellation/current model lookup/optional observations separately. DirectLlmCompressionStrategy sole production implementation. No structured node/summary-budget input, compulsory provider output metadata, concrete dependency in executor, selector/registry, second algorithm or compatibility alias. Independent test implementation must substitute through real orchestration.
- **Retry owner:** strategy performs at most3 total attempts; first success returns, third failure rejects; uniform API/output failures. Fixed abortable1s/2s waits, existing provider timeout policy, explicit stop always stops. SDK single-attempt invocation controls avoid3x3, parent policy untouched. Installed Gemini SDK requires client-level retryOptions, not request-only assumption. Host acceptance/persistence failures and postcommit diagnostics do not cause automatic generation retries. No repair prompt/v6/model switch.
- **A/B mechanism:** existing server AgentRun queue retains B. A's existing native turn/phase is suspended on required compaction failure with its prepared input, not completed or resubmitted. Later genuine user admission after blocked epoch grants one exact one-use permit; same phase compresses/commits, A continues then normal FIFO handles B. Already queued input/during-cycle admissions do not bank future retries. Tool-continuation pause resumes next phase without repeating prior parent/tool work. Generic failed parent calls do not enter replay.
- **Lifecycle:** explicit nonterminal block/resume facts and snapshots, not generic terminal ERROR; active turn remains associated. UI shows error/held input and usable composer, no false complete/reactivation. Command held is outstanding, no terminal TTL/duplicate forwarded observer. Subscription snapshot/revision gives same-process reconnect state, not a disk outbox. Identity and original attachment references preserved. Existing other-runtime append/wait and busy UI unchanged.
- **Cancel/shutdown:** phase wait bound to existing TurnExecutionScope; stale/late output cannot commit. Held-turn shutdown must fence/interrupt before waiting for quiescence to avoid deadlock. Explicit stop never resumes cancelled A. Backend restart has no pending-delivery guarantee and never reconstructs queue from raw history.
- **Persistence:** no new migration. Preserve IR003 current snapshot projection, frozen released classifier/successor preservation, envelope->active-raw repair->full validation, independent category history reads, staged archive->atomic snapshot->install->best-effort prune. Migration guideline reread. No legacy settings import/default init, no history rewrite/deletion.

Classification is based on structural core/provider/server concurrency/shared presentation/web changes, not document or fixture volume. Review independently for supported-path completeness, single retry authority, no generic ERROR terminalization, race-safe permit/queue behavior, cancellation/quiescence, strict DTO routing, no input replay, and clean replacement.
