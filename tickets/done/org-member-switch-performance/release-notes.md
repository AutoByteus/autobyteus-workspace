# Release Notes — org-member-switch-performance

## Improved

- **Faster member switching with the Org tab open.** In long-running Agent Orgs, switching between members with the right-side Org (Messages) tab open used to take 3–4 seconds. It now takes well under 0.1 s in both the desktop app and the browser.

## Changed

- **Reference files in Messages are now compact.** Each message shows a paperclip with its file count. Reference files are listed only under the selected message: the first 20 appear, then a **Show all N files** button lists the rest. References open exactly as before.
- Applies to Agent Org, Agent Team and standalone Messages views (English and Simplified Chinese).

## Not changed

- No server, API or stored-data changes. Mobile is unchanged.
