## iOS app: a new start screen and a built-in demo

- **Try the app without a computer.** The first screen has **Try demo**. It opens the whole app with sample agents, teams and files, with no account, no computer and no network. You can send messages, open files, stop a run and change settings; nothing leaves the phone. **Leave demo** (tap the node name, "Demo / Sample data") returns to the first screen and forgets every change. The demo QR code and the link `autobyteus://demo` open it too.
- **The same first screen as the Android app.** **Scan** a computer's QR code, see **Your nodes**, or use **Other ways to connect** (Type an address, Paste a link). The app shows Connecting, and Can't reach with the reason when a computer does not answer.
- **Share to AutoByteus.** Sharing a pairing link from another app connects to that computer; other text opens Type an address with the text filled in.
- **iPad.** On a wide iPad screen the run list and the open run show side by side; turning the iPad keeps the run open.
- **Download on iPhone and iPad.** **Download** on a PDF or a picture opens the share sheet, with Save to Files and Save Image.
- Computers saved in an earlier version keep working. One that was saved without a name shows as "AutoByteus node" in the app's own list until you scan its QR code again; its run list still shows its name.

## On the phone and the desktop

- After you send a message, the conversation moves to it and follows the reply, also when you had scrolled up.
- Artifacts on the phone are read only.
- The phone's icons are part of the app, so they show without an internet connection.
