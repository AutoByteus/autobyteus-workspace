- Do **not** rely on updatedAt/monitor revision/component force-update for attachments: controlled actual SFC proof shows the raw alias can still retain the computed draft entry. Canonical proxy is the target.
- Do **not** call the original publication failure solved by a different controlled selection ordering. It remains a distinct frontend investigation/validation obligation with bounded escalation if a different writer is found.
