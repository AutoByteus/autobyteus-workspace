## Improvements

- **Open runs keep updating after a lost connection.** When the connection to the node drops, for example when switching from Wi-Fi to mobile data or when the node restarts, an open run now keeps reconnecting and never gives up while it is on screen. When the connection is back, the run shows what it missed and then follows live again. This applies on the phone and in the desktop window, for agent runs, Team members and Org members.
- **Open runs catch up when you return to the app.** After the phone app was in the background or the screen was off, an open run reconnects as soon as you return and shows the replies that arrived meanwhile. While the app is in the background, it makes no connection attempts.
- **A message sent during a busy turn shows once.** A message sent while an agent is still working no longer appears twice when the run is opened on another phone or window during that turn.

Rolling back is possible: install the previous version. Older versions can still read messages stored by this version; no stored data is converted.
