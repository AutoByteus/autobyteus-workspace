## Corrected design and verification contract

- `design-spec.md` DS-005: collect and validate every root/Team/Agent placement in order, call `RunModelSelectionService.validateMany` once for Org creation, require complete results and preserve address-specific errors. Share fresh catalog discovery only within one operation and equivalent runtime/workspace context; no stale process-global model cache and no skipped validation.
- Replace AGY `spawnSync` capability/model discovery on backend request paths with one bounded nonblocking child-process owner, including version/flag/model checks, explicit timeout/process/auth/parse failures, output bounds and cleanup. Propagate awaited results through model catalog, availability/GraphQL/application callers and backend factory; do not alter non-AGY semantics or invent static model slugs. A slow CLI may delay the mutation but must not starve unrelated health requests or leave an endless launch spinner after failure.
- **SR-023 in-progress review clarification:** a probe error cannot be left to current `RunModelSelectionService.validateWithEvidence`, which catches it as reasonless `model_unavailable` and makes Org show “The selected model is unavailable.” The revised DS-005 carries a stable **safe** AGY discovery code/message from capability through catalog, an optional `model_unavailable.catalogDiagnostic`, addressed Org error, existing GraphQL `message`, web store and rendered `launchError` alert; an unexpected AGY catalog exception receives a safe generic discovery-failed diagnostic, while a valid catalog missing the slug remains distinct. Raw child stderr/paths/secrets must not reach the browser. This resolves the Architecture Reviewer's pre-verdict question within the unchanged approved REQ-001/AC-001 behavior; no review Pass has been asserted.
- Required downstream gate: tests for request-local deduplication and distinct-context validation; failed/slow AGY probe with a responsive concurrent `/rest/health`; distinct sanitized discovery-failure versus valid-catalog missing-model messages through GraphQL and rendered browser alert, with `launching` reset; full 18-placement AutoByteus Org browser→real packaged/equivalent backend launch and active persisted tree.
