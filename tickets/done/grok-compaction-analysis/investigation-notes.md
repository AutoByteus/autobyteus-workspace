## Live experiments (raw ACP client launched exactly like AutoByteus; probes/grok-probe.mjs)
- G09 `/compact` on a tiny session (probes/grok-slash-raw.jsonl): sent as a normal prompt, it is executed by Grok (no model reply), `available_commands_update` lists "compact". Notification `_x.ai/session_notification {sessionUpdate:"auto_compact_completed", tokens_before:16542, tokens_after:16542, summary_preview:null}` with `_meta.eventId`, then turn_completed (end_turn). Nothing to compact; no started message.
- G10 Real manual compaction (probes/grok-manualreal-raw.jsonl): after two ~8K-token prompts, `/compact` took ~9.6 s → `auto_compact_completed {tokens_before:32537, tokens_after:21637}`; the next turn used fewer input tokens. **Manual compaction emits only "completed" (no started).**
- G11 Cancel during manual compaction (probes/grok-cancel-raw.jsonl): `session/cancel` 2 s after `/compact` started → turn_completed stop_reason "cancelled" (cancellationCategory MidTurnAbort); **no compaction notification at all**; the next turn shows the uncompacted context. Nothing is left open.
- G12 Automatic compaction (probes/grok-auto-raw.jsonl; temporary GROK_HOME=/tmp/grok-probe/home with a symlinked auth.json and config `auto_compact_threshold_percent = 10`, probes/temp-grok-home-config.toml; the user's ~/.grok untouched): three compactions, each at the start of the next prompt's turn (after the session/prompt request, before the reply): `auto_compact_started {tokens_used:29164, context_window:256000, percentage:11, reason:"Context window 11% full"}` → 12–19 s → `auto_compact_completed {tokens_before:29164, tokens_after:22243, elapsed_ms:12406, summary_preview:null}`. **Started and completed share no operation id** (each has only `_meta.eventId` = sessionId-sequence).
- G13 Cancel during automatic compaction (probes/grok-cancelauto-raw.jsonl): auto_compact_started → session/cancel after 3 s → turn_completed stop_reason "cancelled" with **no completed/cancelled/failed notification**; the next prompt starts a new compaction (started → completed 31230 → 12259 after 36 s). An abandoned "started" is possible, exactly the Codex pattern.
- G14 Not observed: auto_compact_failed / auto_compact_cancelled (exist in the binary; not reproduced).

## Feasibility (evidence)
- Detection: feasible. `_x.ai/session_notification` updates auto_compact_started (auto only) and auto_compact_completed (manual and auto, with tokens and duration) arrive inside the active turn and are already delivered to the Grok profile hook (G03, G04).
- Rotation: rotate on completed; pair started → completed by order within the session (one compaction at a time); close an open started as failed/interrupted at turn end (G13), and treat failed/cancelled notifications as closes if they appear.
- `/compact`: already works natively through AutoByteus's prompt shape (G02, G09, G10); no interception needed.
- Restore: notifications replayed during session/load are ignored by the existing in-turn rule (G04) → no duplicate rotation.
