# Release Notes: Team Tab Tasks Redesign

## Improvements

- Redesigned the Team tab `Tasks` section as a focused master/detail view with Messages open by default and Tasks collapsed with a clear task count.
- Added task-owned reference file previews so delegated task references open in the Tasks detail pane without borrowing Team Communication message identity.
- Simplified task rows by using target names, useful status, task body, and generic `Focus` controls instead of primary `Task Agent` / `Task Team` labels or raw run IDs.

## Fixes

- Kept Approve/Deny actions owned by Activity while Tasks shows only status/read/focus information for delegated work.
- Preserved existing Messages list/detail/reference behavior while aligning the Messages and Tasks headers on the left-side disclosure affordance.
