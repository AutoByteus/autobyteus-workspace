## Improvements

- **The smallest phone text size is gone.** The phone's Text size now has three steps: **Standard** (the default and now the smallest), **Large** and **Largest**. If you had chosen Small, the phone opens at Standard with nothing for you to change.
- **A tidier Text size menu.** The ⋮ at the top right of the run list now shows just the **Text size** heading and the three sizes, without the extra "On this phone" heading above it.
- **Settings is now the last entry of a run's ⋮ menu.** It sits below VNC Viewer when VNC Viewer is shown, as settings usually do. The other entries keep their order.
- The desktop app is unchanged.
