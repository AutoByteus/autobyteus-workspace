## Improvements

- **Text size now covers the whole phone, and it is on the run list.** Tap the **⋮** at the top right of the run list, then **On this phone**, and choose **Small**, **Standard**, **Large** or **Largest**. The choice applies at once to every phone screen: the run list, the conversation, the run's ⋮ views (Artifacts, Files, Messages, Activity, Settings), New run, the connection sheet and the code in the file viewer. The menu stays open so you can see the change as you pick. The conversation's text stays 15, 17, 19 and 21 px; everything else grows and shrinks in the same proportion.
- **Standard looks as it did before.** At Standard the only visible change is the new **⋮** on the run list. Run names and subtitles still stay on one line and end with "…" when they are too long, so at Largest on a narrow phone you may see more "…" in the run list.
- **Your size is kept on the phone.** The phone opens at it from the first screen after a restart. A size you chose in the run's ⋮ menu earlier is kept: nothing to set again.
- **The run's ⋮ menu no longer has Text size.** It is in **On this phone** on the run list.
- **VNC Viewer at large text.** In Control mode, **Keyboard** and **Clipboard** now sit at the right end of the status row under the title bar, so the full-screen button stays on the screen at every text size, also on a 360 px phone. At Standard on a 360 px phone the full-screen button now fits as well.
- The desktop app is unchanged: its text size is still **Settings → Display → App font size**.
