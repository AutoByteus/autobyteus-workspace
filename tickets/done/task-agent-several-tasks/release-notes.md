## Improvements

- An agent or team that is working on a Task can now be given more Tasks while the first is still open, for example a parent Task and its parts. Each new Task's message names the Tasks it already has open, so its reports can say which Task they are about.
- Closing one of those Tasks no longer stops the agent or team while it still has other open Tasks. It stops when its last open Task is Done or Cancelled. The Task page's "Assigned to" line now says so.

## Upgrade Notes

- No data conversion. If you go back to an earlier version, an agent or team that holds several open Tasks there is linked only to its newest one, and an earlier version again refuses to give a busy agent or team another Task.
