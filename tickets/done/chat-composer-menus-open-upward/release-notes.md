# Chat composer menus open upward

## Changes
- **New chat menus open upward.** On the New chat page, the `@` agent/team menu, the `/` skill menu and the Workspace, Model and Thinking menus now always open above the message box instead of dropping below it. They no longer cover the workspace hint line or run off the bottom of the window.
- **Short windows.** When there is little room above the message box, a menu gets shorter and its list scrolls. It does not flip down.
- **The New chat message box sits a little lower** on the page, which leaves more room for the menus above it.
- Narrow windows (under 640px) keep the bottom-sheet menus, and the `/` menu in a running conversation is unchanged.
