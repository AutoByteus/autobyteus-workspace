2. **Native lifecycle spine:** `AgyStreamEventConverter` alone interprets provider `step_update` tool name/state. For `tool_name=generate_image`, publish canonical STARTED with empty public arguments; on `DONE` with no explicit provider error publish SUCCEEDED with `provider_state=DONE` and no `file_path` or raw provider output. **Do not wait for transcript media or inspect AGY brain storage.** The provider `result` closes the turn using normal AGY and `AgentRun` FIFO mechanics; no image-specific private `finalizing`, `providerResultSeen`, transcript baseline, image copy or publication acknowledgment is needed. On native image step `ERROR`/explicit provider error, publish DENIED only when denial is positively identified, otherwise FAILED, using fixed bounded safe public text; keep raw details only in the restricted AGY diagnostic. On **terminal provider result failure**, use the separate safe rule below even when there was no tool step. Non-image tool step behavior is otherwise retained, subject to the same terminal-result public/private boundary. Ordinary successful AGY assistant text may contain its own path; AutoByteus does not parse that prose into an artifact or claim to verify the path.

### Terminal result failure (ARCH-REV-007/F-004)
Only an exact provider `result.status === "SUCCESS"` **with no nonempty `result.error`** may use `result.response` as ordinary fallback assistant text (and only when no assistant text was already streamed), then emit the normal completed turn. A terminal `result` with `ERROR`, another non-success status, missing/invalid status, or a nonempty `result.error` of any type **must not** convert `result.response`, `result.error`, raw status or other provider failure fields into public SEGMENT_CONTENT, ERROR message, status, ACK, trace or history. Close any already-open text segment without adding failed-result fallback text. Emit a fixed bounded public turn failure, e.g. `AGY_TURN_ERROR` / “Antigravity could not complete this turn.”, with `error_scope=turn`, `error_effect=terminal`, the current `turn_id` and `statusHint=ERROR`. This is the terminal app-turn event; do **not** follow it with a misleading `TURN_COMPLETED`/idle success. Normalize any public status to a safe fixed code rather than echoing arbitrary provider status. The backend may return to its normal input-ready phase after this terminal event, while canonical error state remains visible and the next user turn can start through existing FIFO. Tool-step DONE means AGY reported that step DONE, **not** that AutoByteus delivered an image; a later turn-level failure is separately and visibly failed, never converted into an image file claim. An earlier tool-step failure stays failed even if AGY later reports turn SUCCESS; no retroactive green tool card.

Extend the existing AGY restricted diagnostic sink narrowly for a turn-level record `{kind:turn, runId, turnId, safeReasonCode, bounded raw result.status/error/response}` (or an equivalent AGY-local typed shape), with existing no-follow `0700` directory/`0600` file and size limits; it is never projected to public trace/Files/WebSocket or logged raw in backend warnings. Diagnostic-write failure must not alter the fixed safe public error. Do not introduce a transcript reader, a shared redaction framework, a generic queue/publisher change or an app-owned image path. A result-ERROR without any tool step is a first-class test case, not a pathless-DONE failure. For failed terminal results, omit raw `usage` and any other unrecognized result fields from public canonical events unless separately reduced to a known safe scalar contract.

**Dependency rule:** AGY adapter may emit only canonical tool/turn events. Shared `FileChangeEventProcessor`, Files service, REST content route, UI and MCP media service must not gain AGY transcript/brain lookup or special image copy logic. With no explicit native image `file_path` in canonical success and empty public arguments, generic file-change projection has no image path to index. Keep existing projection for other tools/providers; remove now-unneeded AGY native-image stat/projection special case if it is exclusively from the abandoned attempt. Do not promise that async WebSocket, Files or memory observers are synchronously acknowledged by AGY backend callbacks; ordinary existing event semantics apply.
