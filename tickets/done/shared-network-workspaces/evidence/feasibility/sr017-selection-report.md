## Decision supported, not more experimental detours

Selected architecture is **native Apple nfsd/APFS for Mac storage**, **Ganesha VFS/NFS4.1 on native Linux or Docker-on-Linux**, and ordinary Mac/Linux/Docker clients. Docker Desktop serving a Mac source is deferred under ApprovedSR017 DEC012; Mac Docker agent clients are **not deferred**. No UNFS prototype patch ships, and remaining native Git handle defect is no longer a blocker to this selected architecture. Git is only one ordinary-project compatibility test, never the sharing mechanism or a required workspace format.

## Current primary-source and code observations

- Current Go target support: https://go.dev/doc/install/source#environment ; Apple launchd: https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html ; Docker API https://docs.docker.com/reference/api/engine/version/v1.52/ . These support packaging/lifecycle mechanisms, not tested install success. Systemd web retrieval returned403; actual implementation must validate native units, not cite that failure as evidence.
- Ganesha VFS https://github.com/nfs-ganesha/nfs-ganesha/wiki/VFS confirms Linux handle API/capability constraints; actual FR038 is stronger evidence of unsupported tested Mac bind. Docker host-network https://docs.docker.com/engine/network/drivers/host/ supports selected Linux server network placement; no claim that Desktop NAT preserves a remote peer's original identity.
- Apple exports reference https://github.com/apple-oss-distributions/NFS/blob/main/nfsd/exports.5 and Linux NFS manual https://man7.org/linux/man-pages/man5/nfs.5.html inform mapping/mount semantics. Real local engine/version configuration must be validated; no full manual portability guarantee.
- Ubuntu package webpage was inaccessible this round; no fresh package-version claim from it. Actual FR001 build/retained report identifies Ubuntu24.04 Ganesha4.3-8ubuntu1, nfs-common2.6.4 lineage; final artifact manifest locks qualified builds. NFS protocol4.1 must not be confused with engine4.3.
