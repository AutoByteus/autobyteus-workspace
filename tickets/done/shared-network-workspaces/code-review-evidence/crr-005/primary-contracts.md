This matches the selected backend's upstream lineage; installed exact Ubuntu packages are independently recorded by API002 and the reviewer diagnostic.

This report is a hypothesis source, not sufficient proof of the API002 cause by itself; its original FSAL was Gluster rather than this task's VFS.

- [Linux v7.0 NFS procedure owner](https://github.com/torvalds/linux/blob/v7.0/fs/nfs/nfs4proc.c): directory delegation can be requested during directory attribute revalidation. Recognized not-supported results disable the capability and permit retry. This is kernel protocol negotiation, not an application-readiness retry obligation.
- [Linux v7.0 XDR decoder](https://github.com/torvalds/linux/blob/v7.0/fs/nfs/nfs4xdr.c): `__decode_op_hdr` rejects a returned operation number different from the expected one with EREMOTEIO. `decode_get_dir_delegation` expects operation46. This explains why an illegal-operation response can appear to Go/Python as a remote I/O error rather than a permission/regular-file mismatch.
