## What you need to do

- **The update to this version still stops busy agents.** Agents that are in the middle of a task when you install this update stop, as before: message them to continue. From your next update after this one, busy agents continue by themselves after the update restart.
- **If you connected GitHub in an earlier beta:** GitHub is now set up on the new **Integrations** page, and the GitHub card in Settings → Server Settings → Basics is gone. Your token is kept: on the Integrations page, import `https://github.com/AutoByteus/autobyteus-integrations`, and its GitHub card shows as connected. Then give the `github-integration` skill to the agents that should use GitHub; the agent ticks from the old card no longer apply.
