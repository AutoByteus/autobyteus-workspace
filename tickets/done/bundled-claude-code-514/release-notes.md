## Smaller downloads

- The desktop apps and the Docker server package no longer include a copy of Claude Code that was never used. Claude agents keep running with the Claude Code you installed, as before, and the Agent Runtimes settings still show its version, sign-in and update state.
- Downloads are smaller by roughly 75 to 190 MB depending on the platform (for example the macOS Apple-silicon installer drops from about 975 MB to 788 MB, and the Windows installer from about 347 MB to 273 MB); the installed macOS app is about 0.3 GB smaller.
- If Claude Code is not installed on a computer or in a Docker node, Claude agents are shown as not available, as before.
