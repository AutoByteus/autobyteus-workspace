## Improvements
- **Settings for every run on the phone.** Every agent you open on the phone now has **Settings** in its ⋮ menu, including task agents and members of task teams that another agent started, under an agent, a Team or an Org. Settings changes that agent's own runtime and model; for a run that is still live, the red stop button stops that delegated run only, never the agent that started it.
- A run on another computer shows its Settings with "This run is on <node>. Its runtime and model can be changed only on that node."
