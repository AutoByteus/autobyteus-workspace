# Release Notes — `@` can reach agents already in your run

## Fixed

- **You can now `@` an agent or team that is already part of your run.** This includes a collaborator an agent brought in earlier, or a member of the Team or Org you are chatting with. Before, these were missing from the `@` menu, so you couldn't point your agent at them.
  - When you mention one, your agent is told it is already in the run and can message that same instance directly, or start a separate copy if needed.
  - New chats for a Team now list the team's members in the `@` menu too.
- **The `@` menu now says what it does:** "Delegate to an agent or team", and "… gets your message and delegates the work" (English and Simplified Chinese). The old "Bring into this run" wording is gone.
