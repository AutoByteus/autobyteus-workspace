## Changes

- The Work Journal no longer lists Antigravity's own reads of its tool definition files (the files it reads before using one of the platform's tools). These lines said nothing about the work and cluttered the journal and memory search results.
- After updating, journals are rendered again once, in the background, and memory search re-indexes the changed ones; nothing needs to be done and no data is lost: the journals are rebuilt from the raw traces, which still hold every record.
