## Reviewed Design Spec

Round 25 carries forward the complete revised adaptive workspace behavior: one adaptive desktop-capability layout, exact `docked | strip` effective outputs for both sides, one `consuming` strip behavior, explicit hybrid strip actions, origin/personal visual continuity, and mutually exclusive side rendering. A fitting wide user-origin strip emits `redock-panel` and restores the full panel/visible preference; constrained, narrow, or responsive-yield strips emit `open-drawer`, preserve stored preference, and hide that side's strip for the duration of the transient drawer. Dismissal re-evaluates the current policy state and restores the strip or docked panel without preference mutation. Drawer open/closed state remains local transient interaction state and is not a policy presentation. No closed strip is fixed or painted above content; only an open transient drawer may overlay. No leading hamburger/breadcrumb, visible drawer title, separate close X, duplicate panel toggle, or simultaneous strip-plus-drawer state is allowed. The wide default and manual-collapse states preserve the personal-branch left navigation/history + center Work + right tool hierarchy without a generic top-level row. The global `layouts/default.vue` boundary now applies the left panel/strip/transient-drawer model to every non-immersive default-layout route, removes the black responsive header/hamburger/breadcrumb and ordinary `showHeader` compatibility path, keeps route-aware active navigation, and renders workspace right tools only for `/workspace`. Immersive application presentation and `/mobile` (`layout:false`) remain explicit boundaries; no second responsive-policy owner is introduced. The right-tool header also preserves the personal-branch visual contract: one horizontal row, native mouse/touchpad/touch/keyboard scrolling, active/focused-tab auto-scroll, canonical order, original typography/spacing/underline, fixed panel toggle, and no custom fade/chevron/floating-scroll-button/equivalent indicator layer. The global route/renderer branch and strip-flow rework are implementation changes against this approved contract; current source still contains the historical overlay candidate/type/classes and must be updated before source review.

The right-tool header remains one row with preserved visuals and uses native horizontal scrolling plus active/focused-tab auto-scroll in docked and transient drawer containers. It deliberately has no custom edge fades, directional chevrons, floating scroll buttons, or equivalent overflow-indicator chrome. The guaranteed consuming-strip, hybrid activation, DI-010 schema, personal-branch strip/chrome contract, and mutual-exclusion renderer contract are clear in the core design and supplements. Strip visibility is consistently scoped to drawer-closed state, while an open transient drawer is the sole visible surface for that side. The new global-shell contract is equally explicit: the left renderer is shared by every non-immersive default-layout route, the right renderer is workspace-only, and immersive/mobile boundaries bypass the default shell. The no-occlusion contract adds an executable geometry invariant: each closed strip is `relative flex-none w-[50px]`, contributes `consumedWidth = 50`, and is excluded from fixed/z-index overlay positioning; the center/page is laid out after that reservation. Current source drift is bounded to applying that flow geometry, removing the historical overlay candidate/type/classes, and preserving the global renderer boundary; the local drawer gates and no-indicator right-tab row are already present.
