External contract checks: the desktop-file-ID rule maps a subdirectory separator to a hyphen, while simultaneous flat/nested equivalents have undefined selection. This supports preserving the ID but not relying on coexistence. [Desktop Entry Specification](https://specifications.freedesktop.org/desktop-entry/latest/file-naming.html)

Pinned Electron source sets CHROME_DESKTOP in `SetDesktopName`, strips the suffix for XDG identity, and reads that identity when constructing native Linux windows for both backends. The proposed composition location therefore serves this window-matching scope without changing app.name or userData. [SetDesktopName](https://github.com/electron/electron/blob/v42.11.16/shell/browser/api/electron_api_app.cc#L897-L901), [GetXdgAppId](https://github.com/electron/electron/blob/v42.11.16/shell/common/platform_util_linux.cc#L434-L447), [native window identity](https://github.com/electron/electron/blob/v42.11.16/shell/browser/native_window_views.cc#L284-L301)
