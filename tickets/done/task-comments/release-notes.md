## What's New

- Project Tasks now have comments. Add a comment under a Task's description on its Task page or in the Projects tab, without rewriting the description. Comments are numbered, show when they were added, and stay in the order they were added.
- Agents can add comments too, with the Project Task tools. They see a Task's comments when they list Tasks, and an agent that is given a Task receives its comments after the description.
- Board search also finds Tasks by words in their comments.

## Improvements

- When a parent Task is set to Done or Cancelled and one of its parts cannot be closed, the result now names that part, so it can be handled.

## Upgrade Notes

- Existing Tasks need no conversion. They simply have no comments.
- Going back to an earlier version keeps your Tasks, but an earlier version drops the comments of any Task it saves.
