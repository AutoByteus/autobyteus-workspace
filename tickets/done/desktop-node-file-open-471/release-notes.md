## Improvements
- In a desktop window that shows a Docker node or a node on another computer, a file a conversation names now opens wherever it is on that node, not only inside the run's folder: click the path and the file opens read-only in the Files panel. Text, Markdown, images and PDFs show as for workspace files. A path that cannot be opened says why: "This file was not found on the computer.", "This path is a folder, not a file." or "The file preview could not be opened."
- A file path in a run that another node runs now says which node it is on: "This file is on <node>, where this run runs.", on the desktop and on the phone, for file links and attached paths.
- The phone shows a text file of any size in full; the "too large" limit is gone.
