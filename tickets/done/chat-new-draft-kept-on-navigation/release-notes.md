# Release Notes — New chats are kept as Drafts

## Changed

- **A New chat you started typing is no longer lost when you leave it.**
  - Once a New chat has text, it is kept as a Draft. Its one-line row sits directly under **Chat** in the left panel, newest first.
  - Clicking the row brings the draft back exactly as you left it: text, attached files, `/` skills, `@` mentions, the agent or team, workspace, model and its settings, Auto-approve and team member settings.
  - **Chat**, the pencil, **Run**, **+** and the workspace **+** all open a fresh New chat. Your earlier drafts stay in the list.
  - The **×** on a row discards that draft.
  - Sending a draft removes its row; the conversation continues in the new run. If the send fails before the run opens, the draft and its row stay.
- Drafts last for the current session only. A reload or restart starts with none.
