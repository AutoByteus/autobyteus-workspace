# Release Notes — Run settings, unified

## What's new

- **Start Agents and Agent Teams from New chat.** Run on an Agent or Agent Team opens New chat for it, with its default settings in the message box controls: workspace, tool approval, model and thinking. Your first message starts the run.
- **Customize Team members in one place.** A line under the message box shows how many members use the Team's settings. "Customize members" opens a resizable Member settings panel where each member can use its own model, thinking and tool approval.
- **A short launch page for Agent Orgs.** Run on an Agent Org opens one settings card with a Run button. It has the same controls and the same Member settings panel, and a placed team can also use its own workspace.
- **Switch what you run from the heading.** Click the name at the top of New chat or the Org launch page to choose another agent, team or org. Your workspace, approval and model settings come with you.
- **"+" starts another run like this one.** On an Agent, Team or Org run, "+" opens a new start page prefilled with that run's settings, including member customizations.
- **Fast mode.** Models that support it (for example Codex) show a "⚡ Fast" toggle next to Thinking, in the message box, for members and in saved-run settings.
- **Cleaner saved-run settings.** Each saved run shows a Running/Stopped badge and a stop button. Fixed values carry lock icons, and a Save bar appears only when you change something.
- **`@` always brings a collaborator into the run.** In New chat and in running chats, `@` lists Agents and Agent Teams and never switches who you are talking to. Mentions in the first message are kept.
- **Tools on start pages.** A "Show tools" icon opens Files and Terminal for the workspace you chose, before the run starts.

## Changes

- The old long Agent, Team and Agent Org run configuration forms are removed.
- New Agent Org runs now default to Auto-approve, like Agents and Teams.
