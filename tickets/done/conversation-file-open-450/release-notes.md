## Fixes

- **Attached files open on the phone.** Images, PDFs and text files attached to a conversation now show and open in the phone's own viewer, both in sent messages and in the message you are writing. Images show as thumbnails, and Back returns to the conversation. Tapping an attachment no longer shows "Pair this phone again".
- **Files always open with their current content.** Opening a file again, from a link in the conversation, an attachment or the Files tab, now shows its latest content, on the desktop and on the phone. An unsaved edit in an open file is kept.

## What you need to do

- **Android:** install the new version of the AutoByteus Android app. The phone page's fix comes with the node update; the updated app also stops a stray file link from ever showing the pairing screen.

Rolling back is possible: install the previous version. No stored data changes.
