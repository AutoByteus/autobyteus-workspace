Origin/personal behavior
1. RunConfigPanel derives the selected existing TeamRun configuration from
   teamContextsStore.activeTeamContext.view.getConfigurationView().
2. The selected existing TeamRun goes through TeamRunConfigForm, the same form
   used for new TeamRun configuration, with readOnly=true.
3. TeamRunConfigForm preserves Team Definition, runtime/model/model-specific
   fields, Workspace Directory, Auto approve tools, Team Members Override, and
   member controls. It disables edits while keeping disclosures operable.
4. Origin/personal tests explicitly assert that a selected existing TeamRun
   renders TeamRunConfigForm read-only and does not mutate its stored snapshot.
5. Origin/personal has no StoredTeamRunConfigForm.vue,
   StoredTeamRunConfigTree.vue, or StoredLaunchConfigurationCard.vue.

Integrated behavior
1. RunConfigPanel branches selected existing TeamRuns to
   StoredTeamRunConfigForm rather than TeamRunConfigForm.
2. StoredTeamRunConfigForm adds a root wrapper card, “Stored root Team
   defaults,” '/', a standalone key/value configuration card, a separate
   “Stored Team and Agent configuration” section, address-heavy Team/Agent
   cards, and a read-only footer.
3. StoredTeamRunConfigTree and StoredLaunchConfigurationCard create a second
   visual language rather than placing exact stored values into the shared
   configuration controls.
4. The separate stored components are new on the ticket branch and absent from
   origin/personal.

Finding
- USER-UX-003 / Requirement Gap / Design Impact.
- The persisted TeamRunConfigurationView is a correct distinct data contract
  for exact stored topology and values. It does not justify a distinct visual
  form. The implementation incorrectly coupled data-model separation to a new
  read-only card UI.
- Correct direction: one configuration-form presentation for editable and
  stored modes. Stored mode consumes the immutable stored view directly,
  disables mutation, and preserves exact topology/values without converting
  the snapshot into editable intent or consulting mutable current definitions.
