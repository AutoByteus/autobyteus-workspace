# AutoByteus Mobile Privacy Policy

_Last updated: June 28, 2026_

AutoByteus Mobile is a native iOS companion app for connecting to an AutoByteus desktop or server node chosen by the user. The iOS app is designed as a client/wrapper for the user-selected AutoByteus node and does not provide a hosted AutoByteus cloud account by default.

## Data collected by the iOS app developer

The AutoByteus Mobile iOS app itself does not collect personal data for the app developer.

The app may store the following information locally on the user's device so the app can reconnect to the user's node:

- saved AutoByteus node URL or display name;
- local connection state needed to open the saved node;
- pending shared text or links that the user intentionally shares into the app.

This information is stored on the user's device and is not sent to the app developer by the native iOS app.

## Camera and QR scanning

AutoByteus Mobile may request camera access only so the user can scan a Phone Access QR code from their AutoByteus desktop or server node. Camera frames are used locally for scanning and are not stored or sent to the app developer by the native iOS app.

## Connecting to an AutoByteus node

When the user connects AutoByteus Mobile to an AutoByteus node, the app communicates with the node URL selected by the user. Data exchanged with that node is controlled by the node operator and by the user's AutoByteus deployment. If the user connects to their own self-hosted node, that data is handled by their own system. If the user connects to a node operated by another party, that party may process data according to its own policies.

AutoByteus workflows may also use external model providers, tools, or integrations configured by the user or node operator. Those services are outside the native iOS app and are governed by the relevant service terms and privacy policies.
